Publish

Publish now runs a cycle immediately instead of waiting for the next one, which at the stationary cadence can be an hour away. Rewrite the whole site republishes every HTML, CSS, JavaScript and icon file — around 700 kB — on top of that. A plugin upgrade already does this by itself; the button is for what a version number cannot see, like a file deleted by hand on GitHub or a commit that landed half-way.

Voyages

days

Removing a voyage deletes its GPX file from the repository and its row in the track index. It stays in the repository's git history; what goes is the copy the site serves. Remove on a row takes that one day and it stays removed. Today's track is never removed — the position index still holds its points and the next cycle would write it straight back.
